# 壁纸资源列表

两个**独立**页面，互不影响：

| 页面 | 地址 | 说明 |
|------|------|------|
| 独立入口列表 | `index.html` | 顶栏「壁纸」；点击资源直接进详情（不先下载） |
| 更换壁纸页 | `change.html` | 顶栏居中「更换壁纸」；首次点击下载进度，完成后再点回编辑 |

## 独立入口（index.html）

- 顶栏：返回 +「壁纸」| 搜索 + 更多
- 点击资源 → `detail.html`（展示缩略图，不走下载）
- 右下角可显示下载标识（仅视觉）

## 更换壁纸（change.html）

- 顶栏：取消 | 居中「更换壁纸」| 搜索
- 首次点击 → 圆形下载进度；完成后标识消失
- 再次点击 → `edit.html` 返回编辑框架

## 预览

- 独立入口：`http://127.0.0.1:8080/wallpaper-labels/index.html`
- 更换壁纸：`http://127.0.0.1:8080/wallpaper-labels/change.html`
