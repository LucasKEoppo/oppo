# 运营后台 - 定投配置原型

运营后台「新增」弹窗，用**定投配置**替代原「适用机型」配置，支持全部定投标签条件筛选。

## 变更说明

| 之前 | 现在 |
|------|------|
| 适用机型（品牌 + 机型双下拉） | **定投配置**（完整条件筛选） |

## 表单字段

- 标题、词条id、栏目顺序、资源类型
- **定投配置**（选填）
  - 命中逻辑：满足任意条件 / 满足所有条件
  - 条件表格：条件类型 + 条件筛选
  - 白名单
- 操作理由

## 支持的全部定投标签

年龄段、机型、OS版本、客户端版本、品牌、安卓版本、账号类型、营销中台标签、OS数字版本、会员用户、会员签约状态、启动来源（实时）、设备类型、内外销设备用户、是否屏蔽未成年模式标识、OS系统特性、运行内存大小、红薯用户
