# 运营后台 - 新增配置原型

运营后台「新增」弹窗，定投标签支持全部条件类型配置（参考条件筛选面板）。

## 表单字段

- 标题、词条id、栏目顺序、资源类型
- **定投标签**（替代原「适用机型」）
  - 命中逻辑：满足任意条件 / 满足所有条件
  - 条件表格：条件类型 + 条件筛选
  - 白名单
- 操作理由

## 支持的条件类型

年龄段、机型、OS版本、客户端版本、品牌、安卓版本、账号类型、营销中台标签、OS数字版本、会员用户、会员签约状态、启动来源（实时）、设备类型、内外销设备用户、是否屏蔽未成年模式标识、OS系统特性、运行内存大小、红薯用户

## 预览

http://localhost:8080/ops-backend-prototype/index.html

点击「新增」打开弹窗，点击绿色「+」可添加更多条件行。
