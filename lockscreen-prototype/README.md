# 编辑框架内付费资源应用原型

模拟锁屏编辑页点击「应用」后的付费资源弹窗流程。

## 交互流程

```
锁屏编辑页
  └─ 点击「应用」（未解锁）
       └─ 弹窗1：「***」为付费资源
            ├─ 做任务免费领 → 弹窗4 → 赚金币免费兑 → 转圈应用
            ├─ ¥ 6.0 购买   → 弹窗3 → 立即开通/购买 → 转圈应用
            └─ 取消         → 关闭弹窗

  └─ 点击「应用」（已解锁）→ 转圈应用进度 → 完成
```

解锁或应用时会显示半透明遮罩 + 转圈动画 + 蓝色环形进度条，约 2.5 秒后完成。

## 预览

在浏览器中打开 `index.html`，或启动本地服务：

```bash
cd lockscreen-prototype
python3 -m http.server 8081
```

访问 http://localhost:8081/index.html

## 自定义资源名

修改 `app.js` 中的 `RESOURCE_NAME` 即可更换弹窗标题中的资源名称。
