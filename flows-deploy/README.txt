上传部署说明
============

请上传本目录全部内容，或上传 flows-deploy.zip。

要求：
1. 压缩包解压后，根目录必须直接看到 index.html（不要多一层文件夹）
2. 上传整个文件夹时，选择包含 index.html 的这一层

正确结构：
  index.html
  01-wallpaper-entry/
  02-theme-entry/
  03-change-wallpaper/
  04-search-independent/
  05-search-in-edit/

错误示例：
  flows-deploy/index.html   ← 多包了一层，平台会提示找不到 index.html
