# 多付费资源解锁原型

编辑框架内同时选中多个付费资源（壁纸、图标、样式等）时的批量解锁流程演示。

## 场景

用户在锁屏编辑页同时修改了：
- 壁纸：风来啦全局（¥6.0）
- 图标：山海图标包（¥6.0）
- 样式：流光景深（¥3.0）

点击「应用」后进入多资源付费结算弹窗。

## 流程

```
编辑页（含付费提示条）
  ↓ 点击「应用」
多资源付费弹窗
  ├─ 开通 VIP，应用全部已选装扮 → 购买方式弹窗
  ├─ ¥12.8 打包购买并应用 → 购买方式弹窗
  ├─ 做任务免费领 → 免费领弹窗（汇总金币）
  ├─ 选择购买 → 勾选资源 → 购买方式弹窗
  └─ 取消
  ↓ 完成购买/兑换
正在应用 → 已应用
```
