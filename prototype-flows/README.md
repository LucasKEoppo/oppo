# 含原型图的流程图

将产品逻辑流程图整理为**逐步原型截图故事板**。

## 想直接看图？点这里（不要点 HTML 源码）

1. **推荐**：打开 [`查看原型图.md`](查看原型图.md)（Markdown 预览会直接出图）
2. **图片文件**：打开 [`previews/`](previews/) 里的 PNG（点开就是图）
3. **图集页**：用 Live Preview 打开 [`gallery.html`](gallery.html)

## 可交互 HTML 故事板（需 Live Preview，不要当源码看）

在 Cursor：`Ctrl+P` → **Live Preview: Show Preview**，再打开：

- [`gallery.html`](gallery.html) ← 图集预览（最省事）
- [`index.html`](index.html) ← 5 条卡片入口
- 或 `preview.html?p=flows-gallery`
