# 全部灵感主题列表

主题资源栏目列表原型。

## 标识规则

- 全部卡片左上角：小刷子标识
- 部分付费资源：左上角「刷子 + 付费」胶囊
- 全部卡片右下角：下载按钮
- 点击下载：按钮变为环形进度条（灰轨 + 白弧 + 前端圆点）
- 下载完成：进入锁屏编辑框架页
- **免费资源**：编辑页点「应用」→「正在应用...」
- **付费资源**：点「应用」→「购买后即可使用」弹窗 →「去购买」进主题商店详情 → 购买完成后回编辑页 → 再点「应用」可正常应用
- 资源缩略图统一蓝色系占位

## 预览

`Ctrl+P` 打开 `theme-list-prototype/index.html`  
- 免费示例：下载未标「付费」的卡片（如 `lc-2`）  
- 付费示例：下载标「付费」的卡片（如 `lc-1`），或直接打开  
  `edit.html?id=lc-1` / `store-detail.html?id=lc-1`
